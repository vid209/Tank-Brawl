TANK BRAWL (описание и руководство) Первая 1 (Ч. 1)

TANK BRAWL это браузерная мультиплеерная танковая аркада с четырьмя режимами: офлайн против ботов, захват флага, PVP на одном ПК и сетевая игра через Hamachi.

Режимы игры

Офлайн против ботов
Бесконечные волны вражеских танков. Уничтожай ботов, разрушай стены и набирай очки. Когда все боты уничтожены приходит новая волна.

Захват флага CTF
Забери вражеский флаг красный квадрат в правом верхнем углу и доставь его на свою базу золотой домик в левом нижнем углу. Боты будут мешать.

PVP 2 игрока на одном ПК
Сражайся с другом на одной клавиатуре.
Игрок 1 зелёный: стрелки и пробел.
Игрок 2 красный: WASD и X.

По сети через Hamachi
Играй с друзьями через интернет. Нужен запущенный сервер и Hamachi-IP. Поддерживает 10 и более игроков одновременно.

Управление

Движение: стрелки влево вправо вверх вниз
Выстрел: пробел
Перезапуск: R
Выход в меню: ESC
Движение 2-й игрок в PVP: WASD
Выстрел 2-й игрок в PVP: X

Система очков

Разрушение стены: 10 очков
Уничтожение бота: 100 очков
Попадание в игрока PVP: 50 очков
Уничтожение игрока PVP: 200 очков
Захват флага CTF: 150 очков
Доставка флага CTF: 500 очков

Как играть по сети через Hamachi

Важно: для сетевой игры нужен запущенный сервер server.py и установленный Python. Без сервера подключиться не получится.

Шаг 1. Скачай и установи Hamachi
Зайди на сайт hamachi.cc и скачай бесплатную версию LogMeIn Hamachi. Установи как обычную программу, везде нажимай Далее и Согласен.

Шаг 2. Создай сеть, делает хост
Запусти Hamachi.
Нажми Создать новую сеть.
Заполни поля:
Название сети: любое, например TankBrawl
Пароль: любой, например 123
Нажми Создать. Скопируй ID сети, он виден сверху.

Шаг 3. Подключи друга
Друг должен:
Запустить Hamachi.
Нажать Подключиться к существующей сети.
Ввести ID сети, который ты ему дал.
Ввести пароль, который ты придумал.
Нажать Подключиться. 

⚠️( **!!ДЛЯ ТЕЛЕФОНОВ!!** Установить мобильную версию Hamachi
Hamachi поддерживает Android (требуется Android 11 или выше) и iOS. Найдите «LogMeIn Hamachi» в официальном магазине приложений и установите, затем войдите в ту же сеть, что и на компьютере.)⚠️

2. На компьютере всё равно нужно запустить сервер
На телефоне нельзя запустить server.py. Поэтому:

Хост (тот, у кого есть компьютер) должен сначала запустить python server.py.

Телефон и компьютер должны быть в одной сети Hamachi.

В браузере телефона откройте страницу игры, введите Hamachi-IP хоста (не localhost, потому что сервер не на телефоне).

3. Ввести IP-адрес в браузере телефона
Интерфейс игры должен нормально отображаться в мобильном браузере ОТЛИЧНО писать IP проблем не должно не взникать.

⚠️ Практические ограничения
Сервер только на ПК: server.py — это скрипт на Python, на телефоне его не запустить. Телефон может быть только клиентом.

Мобильная версия Hamachi — это не полноценный клиент для ПК: функционал может быть урезан, но для базового подключения к сети должно хватить.

Управление: в игре нет мобильных кнопок, на телефоне, скорее всего, потребуется внешняя клавиатура или придётся смириться с неудобствами.

Если у вас нет компьютера, который может работать в качестве сервера, то сетевую игру на телефоне запустить не получится. Если компьютер есть, то инструкция простая: на компьютере запустите Hamachi и сервер, на телефоне установите Hamachi и войдите в сеть, затем в браузере телефона введите IP-адрес компьютера.


Шаг 4. Узнай IP-адреса
В Hamachi у каждого участника будет свой IP вида 25.12.34.56.
Хост в игре вводит localhost.
Друг вводит Hamachi-IP хоста, тот что виден у хоста в программе.

Шаг 5. Запусти сервер
Сервер написан на Python, поэтому нужен установленный Python.
Открой папку с игрой, там где лежит server.py.
В проводнике щёлкни по адресной строке, введи cmd и нажми Enter, откроется командная строка в этой папке.
Выполни команду:
python server.py
Если Python не находится, попробуй:
py server.py
Если всё правильно, в консоли появится сообщение вроде Server running on port 8080. Не закрывай это окно, оно и есть сервер.

Шаг 6. Запусти игру и подключись
Открой игру TANK BRAWL в браузере.
Нажми кнопку ПО СЕТИ.
Хост вводит localhost, друг вводит Hamachi-IP хоста.
Нажми НАЧАТЬ ИГРУ и играйте вместе.

Важные моменты
Сервер должен быть запущен до того, как игроки пытаются подключиться.
Если друг не видит твой Hamachi-IP, проверь, что он успешно подключился к твоей сети и статус В сети.
При ошибках в игре попробуй временно отключить брандмауэр Windows или разреши Python доступ к сети.
Если друг не может подключиться к серверу, перезапусти Hamachi и попробуй снова.
Если python не распознаётся, значит Python не добавлен в PATH. Попробуй py server.py или переустанови Python с галочкой Add Python to PATH.
Если порт 8080 занят, закрой программу, которая его занимает, или проверь, не запущен ли сервер дважды.

Советы по игре
Прячься за стенами от вражеских пуль.
Разрушай стены врагов, чтобы лишить их укрытий.
В режиме с флагом продумывай маршрут заранее.
В PVP используй неожиданные манёвры.
В сетевом режиме координируй действия с союзниками.

Технические детали
Размер поля 800 на 600 пикселей.
Частота обновления 60 кадров в секунду.
Сетевой порт по умолчанию 8080.
Работает в любом современном браузере.
Для сетевой игры требуется Python и запущенный server.py.

Частые вопросы

Почему не работает сеть?
Проверь, что сервер запущен командой python server.py и порт 8080 открыт.

Можно ли играть через интернет без Hamachi?
НЕТ, мы Ещё не сделали другой способ подключение.


Как перезапустить игру?
Нажми R или выбери режим заново.


Что делать, если python не распознаётся?
Попробуй py server.py или переустанови Python с галочкой Add Python to PATH.




TANK BRAWL - Сетевая игра Часть 2 (Ч. 2)

Что это
Простая танковая игра в браузере. Можно играть офлайн или по сети через Hamachi + Python-сервер.

Что лежит в репозитории
- index.html - игра (открывается в браузере).
- server.py - Python-сервер для сетевой игры (нужен только хосту).

Что нужно скачать отдельно
Эти программы не лежат в репозитории, их нужно установить на компьютер хоста:

1. Python - чтобы запустить server.py.
   Скачать: https://www.python.org/downloads/
   Важно: скачивай "Python Install Manager" (MSIX), а не старый exe-установщик.
   После установки открой CMD и выполни: py install default
   Эта команда сама скачает и установит Python. Галочку "Add to PATH" ставить не нужно.

2. Tunnex - чтобы игра работала онлайн через GitHub Pages (обход блокировки ws://).
   Устанавливается одной командой в CMD: pip install tunnex
   Если команда tunnex не находится, используй python -m tunnex.
   
   После установки запускай туннель так:
   python -m tunnex http 8080
   
   (В старых версиях было tunnex --port 8080, но сейчас правильный синтаксис: tunnex http 8080)

Как запустить сетевую игру (хосту)

1. Установи Python (см. выше) и выполни в CMD: py install default
2. Установи Tunnex: pip install tunnex
3. Запусти сервер:
   - Открой CMD (командную строку).
   - Перейди в папку, где лежит server.py. Например:
     cd C:\Users\Lenovo\Desktop\TankBrawl
   - Запусти сервер командой:
     python server.py
     или, если python не находится:
     py server.py
   - Ты должен увидеть в окне:
     Сервер запущен на порту 8080
     Не закрывайте это окно, пока играете!
   - Это окно нельзя закрывать, пока играете. Сервер работает, пока оно открыто.
4. В новом окне CMD (не закрывая первое) запусти туннель:
   python -m tunnex http 8080
5. Tunnex покажет адрес вида https://random-words.tunnex.org. Скопируй его.
6. Открой игру (index.html), вставь этот адрес (без https://) в поле для IP, нажми "Проверить соединение".
7. Если всё ок - нажми "Начать игру".

Как подключиться другу

1. Друг открывает игру по ссылке GitHub Pages (или скачивает index.html).
2. Вводит тот же адрес Tunnex, который ты ему дал.
3. Нажимает "Проверить соединение" и "Начать игру".

Важно
- server.py и tunnex запускаются только на компьютере хоста.
- Другу не нужно устанавливать Python или Tunnex - он просто открывает игру и вводит адрес.
